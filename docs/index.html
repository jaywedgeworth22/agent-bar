What It Reads

CodeCaps reads each CLI's own saved credentials, in place — nothing is typed, ever.

  • Claude — quota windows (5-hour and weekly), read from ~/.claude/.credentials.json or the Keychain.
  • Codex — rate-limit windows, read from ~/.codex/auth.json.
  • Antigravity — pooled Gemini and Claude & GPT quota, read via the antigravity-usage CLI and Antigravity's own language server.
  • Cursor — included-plan usage, read from Cursor.app's local session database.
  • Grok CLI — billing and credits, read via Grok's CLI proxy from ~/.grok/auth.json.
  • Grok Bot — weekly usage, read via Cursor's dashboard service, from that same session database.
  • MiniMax — per-model and weekly remaining quota, read from ~/.mmx/config.json.

The first time a freshly installed CodeCaps needs Claude Code’s Keychain item, macOS asks whether to let it through.  The login Keychain grants access per app, so a brand new CodeCaps is a brand new app to it, and Claude can read as signed out while Claude Code is signed in.  Press Allow Access To Claude Code on the Claude row in Settings → Sources & Fleet and choose Always Allow: it is asked once, it is a read, and CodeCaps never writes to or removes Claude Code’s saved login.

Fleet Push And Pull

CodeCaps can push this Mac's quota windows to an endpoint you run, and pull other machines' windows back into the same view.  Both are off by default, and nothing leaves this Mac until you turn one on and enter an endpoint yourself.  The two secrets it stores, an ingest token and a read token, live in the macOS Keychain, never a config file.

How The Headline Number Is Chosen

A collapsed row in Glance, or a card in Console, always shows the fresh window closest to its cap, the lowest remaining percent, alongside that window's own reset countdown.  The menu bar has its own setting, Menu Bar → Displayed Quota, choosing the lowest active quota by default, the lowest quota outright, or one window pinned by name.  Console's Next Reset tile is the soonest reset across every fresh window on every platform, not just whichever window is nearest its cap.

Is This For You?

If you only run one Mac, better tools already exist: steipete/CodexBar and tddworks/ClaudeBar both cover more providers than CodeCaps does, and both are free, signed, and notarized.  CodeCaps exists for a different job, reading quota into a collector you run yourself and pulling it back across every machine you use.
